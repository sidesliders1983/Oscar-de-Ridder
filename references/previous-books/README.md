# Eerdere boeken

Boek 1 en boek 2 zijn continuïteitsbronnen voor boek 3 en mogen niet worden herontworpen. De submappen zijn nog leeg op deze instructies na.

Leg bij import titel, editie/versie, herkomst, goedkeuringsstatus, relevante pagina/spread en betekenis voor boek 3 vast. Bewaar originele bronbestanden ongewijzigd. Ontbrekende inhoud niet afleiden of verzinnen.
